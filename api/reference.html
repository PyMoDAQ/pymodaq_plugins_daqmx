Reference

Public API to describe and run NI-DAQmx tasks from any Python code.

It never imports Qt nor the PyMoDAQ GUI. See the documentation for the stability promise.

System

class pymodaq_plugins_daqmx.hardware.national_instruments.api.NIDAQSystem[source]

Bases: object

A view of the NI hardware, read from the driver once and kept until refresh().

Without the NI-DAQmx driver there is simply no device. Everything returned is made of plain strings, numbers and tuples. A device or a kind of channel that does not exist is a ValueError; a property the device does not have (for instance the maximum rate of the analog outputs of a card without any) is None or an empty list.

class pymodaq_plugins_daqmx.hardware.national_instruments.api.TaskListener[source]

Bases: object

What a task can tell: derive from it and register the object with task.add_listener.

Both methods are called from driver threads, never from the thread that started the task, one thread per call and without any order between them. Do only what is thread-safe here, or hand the event over to the thread that should handle it (see QtTaskBridge).

class pymodaq_plugins_daqmx.hardware.national_instruments.api.TaskGroup(*tasks: _Task)[source]

Bases: object

Tasks that run together, such as a task waiting for a clock and the counter that generates it.

One task cannot mix subsystems (analog in, analog out, digital, counters): to acquire and generate at the same time, use one task per subsystem, synchronised by a shared clock or trigger (ClockSettings.source, DigitalEdgeTrigger). The group starts them in the order given, so put first the tasks that wait for a signal and last the one that produces it, and stops and closes them in the reverse order.

If a task cannot start, the ones already started are stopped and the error is raised. All the tasks are closed even if one of them cannot be, then the first error is raised.

class pymodaq_plugins_daqmx.hardware.national_instruments.api.ClockSettings(rate: float, samples: int | None = None, source: str = '', edge: Edge = Edge.RISING)[source]

Bases: object

Acquire samples samples per channel at rate Hz, or until stopped if samples is None.

source is a terminal such as /Dev1/PFI1 to use an external clock; empty means the onboard clock. A continuous acquisition (no samples) is read through on_samples_ready (start(notify_every=n)), with a driver buffer holding at least one second of data.

class pymodaq_plugins_daqmx.hardware.national_instruments.api.ImplicitTiming(samples: int | None = None)[source]

Bases: object

No sample clock: the pace is given by the task itself, not by the onboard clock.

Use it for counter output: the counter itself generates the pulse train (continuous, or samples pulses). For a counter input that is read on demand, give no timing at all (timing=None): each read returns the count at the moment of the call. To count at a regular pace, use ClockSettings with a source.
