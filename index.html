Welcome to pymodaq_plugins_daqmx’s documentation!

This PyMoDAQ plugin is devoted to the National Instrument signal acquisition and generation using the NiDAQmx library. It contains generic objects which should be used as a basis to build actuators and viewers performing custom signal acquisition and generation. In addition, and they are also meant as examples, it provides actuator plugins which can be used to move piezo scanners using the analog output functions of NI acquisition cards, as well as a 0D viewer corresponding to a single photon counter.

This documentation is written as a tutorial to guide you when setting up your NI acquisition devices with PyMoDAQ.

Caution! The 0D and 1D Viewers DAQmx and the Move DAQmx deliver basic solutions. Write your own plugin for your specific needs.

This plugin is compatible with PymoDAQ 5.
